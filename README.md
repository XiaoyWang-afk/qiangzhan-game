# 枪战 · 霓虹围城

一款俯视角街机生存游戏。操控霓虹战机，对抗侦察机、冲锋机、远程射手机，以及每四波出现一次的首领。

## 开始游戏

直接用浏览器打开 `index.html`，或在项目目录运行以下命令，再访问 [http://localhost:8000](http://localhost:8000)。无需安装依赖或构建。

```sh
python3 -m http.server 8000
```

| 操作 | 键盘与鼠标 | 触屏 |
| --- | --- | --- |
| 移动 | `W A S D` 或方向键 | 拖动左半场摇杆 |
| 瞄准和射击 | 移动鼠标，按住左键连射 | 拖动右半场摇杆 |
| 切换武器 | `1` 手枪、`2` 霰弹枪、`3` 冲锋枪 | 点「切换」或底部武器编号 |
| 换弹 | `R`，也可在弹匣用尽后继续射击以自动换弹 | 点「换弹」 |
| 暂停／继续 | `P` 或 `Esc` | 点顶部「暂停」／「继续」 |

初始装备为手枪，备用弹药不限。首波起可拾取并解锁霰弹枪，第二波起可解锁冲锋枪；解锁后手动切换武器。把战机开到补给上即可拾取；敌机有概率掉落生命和弹药补给。每波结束后有短暂休整并恢复部分生命，首领会先标出扇形射击方向再开火。结算显示生存时间，最高纪录保存在当前浏览器中，音效可用顶部按钮关闭。

## 验证

使用 Node.js 内置测试运行器，无需安装依赖：

```sh
node --test arena.test.cjs
```

游戏逻辑在 `arena.js`，Canvas 绘制在 `visual.js`，输入、界面、音效和本地纪录在 `game.js`。
